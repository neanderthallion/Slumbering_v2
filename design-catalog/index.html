Design catalog

Every screen, popup, and component in Slumbering

A browsable reference matching the deployed app — built from the app's target architecture (CLAUDE.md) and the actual on-device screenshots in design-catalog/AppScreen/. Each screen page is a structural HTML/CSS recreation — faithful to real layout, copy, and states — with a light/dark preview toggle and an annotated notes panel, not a pixel-exact export or a live screenshot.

One dusk-purple + gold/blush/sage palette, Quicksand type, soft 16–40px card radii, full-pill buttons/badges, and a fixed pink→gold CTA gradient that never changes with theme. See Design tokens for the full system.

How to read a screen page

Every screen page in this catalog follows the same layout:

  • Header chips — the route name, how it's presented (pushed screen vs. the one native modal), and where its back-navigation goes.
  • Phone-frame mockup — a structural recreation at native app scale, with a "Preview: dark" button to flip that mockup's theme.
  • State tabs — screens with more than one meaningful state (e.g. Check-In's wizard steps, Home's 4 goals-status states, Bedtime's Week/Month) show each as a switchable variant.
  • Notes panel — Purpose, Data & state, Conditional states, User actions & navigation (linked), and Components used (linked to the component reference).
Source: CLAUDE.md (target architecture) and the on-device screenshots in design-catalog/AppScreen/. Not a build artifact — safe to delete or regenerate.
