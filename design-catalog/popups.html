Popups & dialogs

Every overlay/interruption in the app — from a true full-screen Modal to an inline warning box to a passive toast. None of these are separate navigator routes; they're rendered conditionally inside whichever screen triggers them.

Achievement Celebration modal

features/achievements/components/CelebrationModal.tsx — React Native <Modal transparent visible animationType="fade">, full-screen dark scrim behind a centered card.

Badge earned!

★
Full week

Full Week

7 calendar-consecutive nights with at least one goal achieved each night.

TriggerCheck-In, after Confirm, when badge evaluation returns ≥1 new unlock dated today (not already in settings.celebratedAchievementIds).
ContentMascot, a title that varies by unlock type (badge-specific / singular / plural copy). Badge unlocks show the badge medallion + name (gold) + description. Milestone/engagement unlocks show plain sage text instead — never phrased around what was missed.
ActionsSingle primary Close button → closes the modal, then navigates to Home and fires the pending check-in toast.

Disclaimer Dialog

features/goals/components/DisclaimerDialog.tsx — not a true overlay: an inline gold-tinted box injected directly into the scroll flow beneath the goal list.

Sleep experts generally recommend an earlier bedtime. Would you like to continue with this goal?

TriggerGoal Picker, when a selected/added/edited goal label trips looksLikeUnhealthyBedtime — a named bedtime between 12:00am–4:59am.
ContentNon-blocking warning: "Sleep experts generally recommend an earlier bedtime. Would you like to continue with this goal?"
ActionsChange goal (ghost) removes the flagged goal. Continue (primary) dismisses the disclaimer and keeps the goal — never blocks saving.

Time Picker panel

An inline expanding panel appended below whichever time field triggered it, not a modal — used by Home's bedtime/wake fields, Check-In's report-times step, and Settings' reminder rows.

101112 : 550005 PM
TriggerTapping the clock icon on any TimeField — Home's bedtime/wake fields, Check-In's report-times step, Settings' reminder rows.
ContentWraps @react-native-community/datetimepicker's Android spinner.
ActionsAuto-closes on selection (Android's native picker behavior).

Import confirmation (Alert)

features/backup/logic, triggered from Settings' Backup & Restore section — native Alert.alert on Android.

Replace current data?

Importing will replace all current goals, journey history, and settings.

TriggerTapping Import after a valid backup .json file has been picked and its shape validated against the zod schema in lib/schemas.ts.
ContentWarning that import overwrites all current goals, history, and settings — a destructive-confirm gate, never applied partially on shape mismatch.
ActionsCancel / Import → proceeds with the restore.

Toast

features/achievements/components/Toast.tsx — a context provider, not a per-screen component. Called from many screens for save confirmations, export/import results, and check-in feedback.

Backup restored
TriggerSave confirmations, export/import results, date-seeded check-in feedback tiered by full/partial/none completion — never phrased as failure.
ContentBold single-line message on a pill-shaped surface. Animated fade + slide-up, bottom-center.
ActionsNone — passive, auto-dismisses after a few seconds. Never blocks interaction.
This is the app's complete set of popups/dialogs — no others exist in the current codebase.
