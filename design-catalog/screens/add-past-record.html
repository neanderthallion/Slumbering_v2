Purpose

Lets a user log — or correct — a night they forgot to record at the time. Records created here are tagged source: 'backfilled' and show "· Added later" in the Journey timeline.

Data & state

  • Date field defaults to yesterday; tapping it opens an inline date entry. Dates ≥ today are rejected with a toast.
  • Goal selection reuses settings.suggestedGoals[category], same category tabs as Goal Picker — including the pencil-icon relabel affordance, but here it edits a local-only copy, never settings.suggestedGoals itself (the one deliberate exception to the Goal Picker rule).
  • "Did you achieve these?" only appears once ≥1 goal is selected — one Yes/No pill per selected goal.
  • Sleep Schedule is an optional toggle section — switching it on reveals actual bedtime/wake time fields that feed the same ±15 min delta classification as Check-In.

Conditional states

Save stays disabled until every selected goal has an achieved value (Yes/No) filled in.

User actions & navigation

  • Cancel → back (dismiss modal)
  • Save → builds/updates a backfilled NightRecord, saves, goes back to Journey, shows a "saved" toast

Components used

Card, Category tabs, Checkbox, Yes/No pill, Toggle, Button.
