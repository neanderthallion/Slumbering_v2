Purpose

Reviews the previous night: a frictionless yes/no gate on whether sleep went as planned, then marks each of that night's goals achieved or not.

Wizard steps

1 · Ask

Only shown if a planned bedtime/wake exist and sleepConfirmation is unset. Yes sets asPlanned and skips straight to Done — no time entry for the common case. No reveals actual bedtime/wake time pickers.

2 · Report times

Only reached on "No." Actual bedtime/wake via two TimeFields. Continue compares actual vs. planned with a ±15 min tolerance band → on-time / shorter / longer, feeding date-seeded feedback text.

3 · Done

Optional feedback line, then a Yes/No pill per goal. Confirm stays disabled until every goal is answered.

On Confirm

  • Updates the night record with each goal's achieved value and sleepConfirmation/actual times.
  • Evaluates all 7 badges; only ones unlocked today (not already in settings.celebratedAchievementIds) trigger a celebration.
  • Picks a date-seeded check-in toast tiered by full/partial/none completion — never phrased as failure.
  • If new achievements unlocked → shows Achievement Celebration modal first (holds navigation/toast until closed).
  • Otherwise → navigates straight to Home with the toast.

Components used

Card (plain / organic), Button, TimeField, Yes/No pill, AchievementCelebrationModal.
