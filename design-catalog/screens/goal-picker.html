Sleep experts generally recommend an earlier bedtime. Would you like to continue with this goal?

Purpose

Select which sleep goals apply tonight (create mode) or revise today's already-set goals (edit mode, pre-seeded from today's existing record).

Data & state

  • Goal pools: settings.suggestedGoals[category], three categories (Bedtime / Unwind / Relaxation).
  • Editing a suggested goal's label (pencil icon) permanently rewrites the suggestion bank (settings.suggestedGoals), not just that one instance, and auto-selects it. The one exception is Add Past Record's own relabeling, which edits a local-only copy.
  • Custom (non-suggested) goals already selected in the active category render as separate removable rows.
  • looksLikeUnhealthyBedtime() flags a named bedtime between 12:00am–4:59am via regex — non-blocking, shown inline as "Continue" / "Change goal", never prevents saving.

Conditional states

Disclaimer shown

Inline below the card when a selected/added/edited goal trips the unhealthy-bedtime heuristic. See Disclaimer Dialog.

Confirm disabled

"Confirm goals" stays disabled (dim) until at least 1 goal is selected.

User actions & navigation

  • Back row → Home
  • Category tabs filter the suggestion list
  • Cancel → Home
  • Confirm goals (create mode) → Tonight Confirmation, passing the selected goals as a route param
  • Confirm goals (edit mode) → updates today's record directly, returns to Home

Components used

Category tabs, Card, Checkbox, Button, DisclaimerDialog.
