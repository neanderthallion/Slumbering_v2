Purpose

The daily landing dashboard: greeting + companion message, the one action the user needs to take right now, a rolling 7-night recap, and the current bedtime schedule.

Sub-components

ComponentShows
GreetingHeaderTime-of-day / first-time / returning greeting + wordmark + moon mascot.
TodaysMessageCardPriority-ranked companion message (the one asymmetric "organic" card on this screen).
GoalsStatusCardThe 4-state CTA/goals block shown in the preview tabs above.
JourneyPreviewCardLast-7-nights dot graph + strongest goal category over the trailing 7 days. Empty state if no nights logged yet.
BedtimeSchedulePanelRead-only bedtime/wake time + scheduled duration (always the dark "night" card, positioned last); tapping it (outside the two inline time fields) opens Bedtime.

Conditional states (GoalsStatusCard)

No goals set

Gradient CTA pill "Pick your goals for tonight" → Goal Picker (create mode).

Goals set

Tonight's goals already chosen, check-in not yet due — a plain card lists them with an "Edit" link → Goal Picker (edit mode). No button.

Check-in due

Next morning — CTA pill "Did you achieve your goals?" → Check-In, plus the goal list below it.

Both done

Plain card, no CTA — never phrased as failure even if goals were missed.

User actions & navigation

  • Settings gear icon → Settings
  • Primary CTA → Goal Picker or Check-In, depending on state
  • "Edit" link (goals-set state) → Goal Picker (edit mode)
  • Journey preview card "See all →" → Journey
  • Bedtime Schedule panel "See all →" (or tapping the card outside its two time fields) → Bedtime

Components used

Card (plain / organic / night variants), Button, dot-journey graph, illustrations (moon mascot, bedtime crescent, wake-up sun, cloud-sheep).
