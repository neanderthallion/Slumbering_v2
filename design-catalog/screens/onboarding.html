Used to personalize your greetings, optional. You can add or change this later in Settings.

Theme

Purpose

First-run setup. Rendered directly by AppShell in App.tsx whenever settings.hasOnboarded is false — it sits outside the navigator entirely, so there is no header, back button, or route to it from anywhere else in the app.

Data & state

  • Name — local useState, optional free text.
  • Theme — reads/writes live via ThemeContext.setMode, so the whole screen (and app) previews the chosen theme immediately, before onboarding is even complete.

Conditional states

None — a single static form. No loading/error/empty variants.

User actions & navigation

  • Get started — commits the trimmed name and sets hasOnboarded: true, which flips AppShell into NavigationContainer → Home (the navigator's initialRouteName). This is the only way to leave this screen.

Components used

Button (primary), Card, SegmentedTabs-style theme picker, Luna moon mascot illustration.
