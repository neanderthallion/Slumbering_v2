Purpose

The single place for personalization, reminders, appearance, data portability, and app info — no separate settings screens per topic, everything scrolls in one page.

Sub-sections

SectionWhat it does
ProfileSectionEdit display name, committed on blur/end-editing.
RemindersSection3 toggles (Set Goals / Check-In / Unwind) with per-reminder time shown as a subtitle. Unwind's time is always derived from the bedtime schedule, never independently editable.
AppearanceSectionTheme (Light/Dark, gradient-active pill) and Text size (Small/Medium/Large, solid-ink-active pill) — both apply globally and instantly, no restart or navigation needed.
BackupRestoreSectionExport: serializes settings + records to JSON via the OS share sheet. Import: pick a .json file, validate shape with zod, destructive-confirm, then overwrite local state.
AppInfoSectionVersion, then links: Sleep Science (real screen), Terms of Service / Contact Us / Feedback.

Behavior note — Reminders are real

These toggles request notification permission and schedule/cancel real expo-notifications daily reminders — not just a stored preference. Turning a toggle on (a user gesture) calls ensureNotificationPermission(); a denial reverts the toggle with a toast. AppShell re-syncs all three schedules whenever reminders/bedtime change, but only once permission is already granted — it never itself prompts.
