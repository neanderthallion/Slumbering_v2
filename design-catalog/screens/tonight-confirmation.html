Tonight Confirmation

src/screens/TonightConfirmation/TonightConfirmationScreen.tsx — read-only recap of the goals just chosen, params: { goals: NightGoal[] }.

Pushed screen Back row → Home Reached only from Goal Picker (create mode)

‹ Home

Tonight's goals are

✓Sleep before 11:00 PM
✓Stretching for 10 minutes before bed

Rest well tonight. We'll check in tomorrow.

Purpose

A final read-only checkpoint before committing tonight's goals — lets the user glance over the selection once more before it's written to storage.

Data & state

No local state — purely renders route.params.goals. On confirm, builds a NightRecord via createNightRecord (snapshotting the current bedtimeSchedule as plannedBedtime/plannedWakeTime) and calls upsertRecord.

Conditional states

None — always the same layout for whatever goals were passed in.

User actions & navigation

  • Edit goals (ghost) → navigation.goBack() to Goal Picker
  • Confirm (primary) → creates the night record, navigates to Home, fires a success toast

Components used

Card, Checkbox (read-only, checked), Button (primary + ghost).
