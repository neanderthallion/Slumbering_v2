Design tokens

One dusk-purple + gold/blush/sage palette shared by both themes — only surfaces and text invert between light and dark. Two families never flip with theme: the pink→gold CTA gradient, and the "night" surface family used for bedtime/sleep content regardless of the app's active theme. Corners are soft and generous (16–40px on cards, full pill on buttons/badges), and shadows are a soft ambient lift rather than a hard offset. Source: src/theme/tokens.ts (app-native names) — values copied into assets/tokens/*.css use slightly different variable names for the same colors (noted below).

Dot/badge fills: moonFull = gold #f7c877, moonPartial = blush #f2a5c2, moonEmpty = the theme's low-emphasis border color. Text sitting on the gradient is always dark ink (textOnAccent); text sitting on a solid accent-primary fill (the selected Text Size pill) flips with theme instead (textOnPrimarySolid).

Typography

Quicksand only (self-hosted, 500/600/700) for every live text element — loaded via expo-font. The script "Slumbering" wordmark is not set in a font; it ships as a static image asset (Slumbering_title.png) so the brand mark can be a one-off cursive shape without adding a second typeface to the app. Hierarchy in body text comes from weight/scale spread, especially on numerals — see numeralHero below.

wordmark → image asset, not text
numeralHero → Quicksand 700, 46px, tabular — streak counts, sleep duration, completion %

Every bit of effort counts.

A global textScale multiplier (Settings → Appearance → Text size) scales every size: small ×0.92, medium ×1, large ×1.15.

Radius

16–40px radii on structural cards, full pill (999px) reserved for buttons, badges, chips, and toggles. One asymmetric "organic" radius is allowed on exactly one hero/quote element per screen — never reused elsewhere on that same screen.

sm · 12 (checkboxes, small chips)
md · 16 (sidebar links, demo tiles)
lg · 24 (default Card)
xl · 28 (night Card, larger panels)
pill · 999 (button, badge, chip, toggle)
organic — one hero card per screen

Shadow

Soft, ambient shadows — generous blur, low opacity, minimal offset. Most cards read as flush color blocks with little to no visible lift; elevation is reserved for things that genuinely float: primary CTAs, the Journey FAB, and toggle knobs. Warm-tinted in light theme, a plain soft black in dark theme.
